# Portal Interface Design System v1.0

- **Palette:** portal green #00FFAA, blue #44AAFF, purple #A855F7, magenta #FF45E0,
  orange #FF7A45, red #FF4444, yellow #FFCC00, success #22C55E, grays.
- **Typography:** Orbitron (display), Rajdhani (body), JetBrains Mono (telemetry), Inter (fallback).
- **Portal states:** OPEN / STABLE / INSTABLE / COLLAPSING / DESTROYED.
- **Buttons:** OPEN PORTAL (primary), CLOSE PORTAL (secondary), TERMINATE (danger), DISMISS (ghost).
- **Status badges:** ONLINE / VOICE / STABLE / THINKING / ERROR.
- **Icons:** lucide-react set (portal, scan, sync, pulse, upload, archive, mic, send...).
- **Motion:** portal 12s, HUD 20Hz, glow 1.2s, camera 300ms, sidebar 250ms.
