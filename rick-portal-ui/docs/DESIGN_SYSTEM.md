# Design System — Portal Interface

## Colour Tokens
- `--bg-main: #000000` (AMOLED black)
- `--bg-panel: #0A0A0A`, `--bg-glass: rgba(10,10,10,.75)`
- `--portal-green: #00FFAA` (primary), `--portal-blue: #44AAFF` (secondary)
- `--portal-orange: #FF7A45`, `--portal-magenta: #FF45E0`
- `--success: #22C55E`, `--warning: #FFCC00`, `--danger: #FF4444`
- `--text-primary: #E5E5E5`, `--text-secondary: #B8B8B8`, `--text-muted: #888888`
- `--border-glow: rgba(0,255,170,.3)`

## Typography
- Titles: Orbitron / display; Telemetry/HUD: JetBrains Mono.

## Components
- `.portal-card` — glassmorphism panel (blur 12px, 16px radius).
- `.portal-glow` — cyan-green active glow.
- `.status-badge` — online/thinking/error variants.

## Visual Hierarchy
Primary: Avatar, Voice interaction, Portal status.
Secondary: Telemetry, Memory, Inventions.
Tertiary: Downloads, Logs, Settings.
